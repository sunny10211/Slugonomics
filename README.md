# Slugonomics

Financial literacy for UC Santa Cruz students — a UCSC-themed website with:

- **Home** (`index.html`) — decisions, calculators, campus help and the Slugonomics overview
- `assets/` — self-hosted fonts (Bricolage Grotesque, Instrument Sans; SIL Open Font License) and game screenshots
- **Slug Life** (`slug-life.html`) — life sim starting at 18, playable with your real finances
- **Slug College** (`slug-college.html`) — Slug Life version 2, focused on school: four years at UCSC, month by month
- **College Sim** (`college-sim.html`) — a week of college life: money, time, health, grades, social

Languages: English, Spanish, Korean and Simplified Chinese via the picker in the header (homepage, calculators, Campus help, About, My plan). The six decision walkthroughs and the games are English for now.

Static site, no build step. Hosted with GitHub Pages.
