# Slugonomics

Financial literacy for UC Santa Cruz students — a UCSC-themed website with:

- **Home** (`index.html`) — tools, resources and the Slugonomics overview
- **Slug Life** (`slug-life.html`) — life sim starting at 18, playable with your real finances
- **College Sim** (`college-sim.html`) — a week of college life: money, time, health, grades, social

Static site, no build step. Hosted with GitHub Pages.
